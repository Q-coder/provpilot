ProVPilot is a free, open-source flight simulator built on JSBSim flight dynamics and the Godot engine, with photoreal Switzerland and Baden-Württemberg scenery sourced directly from swisstopo and LGL BW. Hop in the Cessna 172, pick an airport, and go.

What is ProVPilot?

A no-friction VFR flight simulator focused on the Alps and Central Europe. The goal: accurate 6-DOF flight physics in a faithful Cessna 172, flown over the actual Swiss landscape — same terrain elevations, same orthophotos, same buildings, roads, rivers, and airports as the real world — all streamed at runtime from a custom C++ Godot extension.

Originally a Godot 3 demo by chunky/jsbgodot, ProVPilot has been rewritten from the ground up for Godot 4.6 with a custom double-precision engine fork — no floating-origin tricks, no jitter at coordinate extremes, and a 200 km+ visible horizon for Alpine panoramas.

Real-world terrain

swisstopo swissALTI3D elevation at 1 m resolution, streamed as 1024 × 1024 m float32 tiles with distance-based LOD.

Photoreal orthophoto

SWISSIMAGE aerial photography mapped per tile with a mip pyramid for far-LOD. Mountains look like mountains.

3D buildings

swissBUILDINGS3D models with per-building detail meshes and a merged far-LOD handoff. Cities have skylines.

Roads, rail & water

swissTLM3D road, railway and waterway network rendered as ribbon meshes. Follow the autobahn home.

JSBSim flight dynamics

Full 6-DOF simulation. Faithful Cessna 172 model with mixture, magnetos, carb heat, prop pitch and trim.

47 Swiss airports

OSM-verified runway geometry. Welcome screen picker — pick LSZH, LSGG, LSPF, LSZB and more in one click.

Gamepad & joystick

Plug-and-play SDL gamepad mapping plus per-axis calibration (min/center/max, invert, deadzone, response curve).

Free & open source

MIT licensed. Code on gitlab.md80.ch. Scenery under the respective free-geodata licenses (swisstopo, LGL-BW, OSM).

Installation

The app itself is a small download (~150 MB). Scenery data is huge (~165 GB for full coverage) and is installed separately from inside the app — pick the regions and quadrants you actually want to fly over.

macOS Apple Silicon

  1. Download the latest ProvPilot-x.y.z-arm64.dmg from the button at the top of this page.
  2. Open the DMG and drag ProvPilot.app into your Applications folder (or anywhere else).
  3. The build is signed and notarized, so first launch from Finder works without right-click → Open.
  4. On first launch, open Settings → Download Scenery and grab Switzerland (base) at minimum. The base pack (~44 GB) gives you terrain, roads, water and airports — flyable on its own. Add the four detail quadrants (orthophoto + buildings + trees) for the corners you actually fly in.
  5. Pick an airport in the welcome screen and click Fly!

Requirements: macOS 12+, Apple Silicon (M1 or newer), ~200 GB free disk for full Switzerland + Baden-Württemberg scenery.

Windows x86_64

  1. Download the latest ProvPilot-Windows-x.y.z.zip from the button at the top of this page.
  2. Right-click the ZIP → Properties → tick Unblock → OK. Then extract it somewhere you can write to (e.g. C:\Users\<you>\ProvPilot\ — not Program Files).
  3. The build is not signed yet. Windows SmartScreen may show "Windows protected your PC" the first time. Click More info → Run anyway.
  4. Launch ProvPilot.exe.
  5. Open Settings → Download Scenery and grab at least Switzerland (base). Same two-tier model as on macOS.
  6. Pick an airport and click Fly!

Requirements: Windows 10/11 x64, dedicated GPU with Vulkan support recommended, ~200 GB free disk for full scenery.

Trouble? Logs are written to %APPDATA%\Godot\app_userdata\ProVPilot\logs\godot.log — send the file with any bug report.

Cockpit interaction

Switch to the cockpit camera (C) and click-drag the mixture lever, throttle, flap lever or magneto/ignition switch with the mouse. Levers track the pointer with visual feedback.

Half-axis joysticks (e.g. Logitech Dual Action) work too — rebind the offending axis in Settings → Joystick or fall back to the keyboard.

Scenery coverage

Scenery is split into one base pack per region (terrain, roads, water, airports — flyable on its own) and four detail quadrants (NW / NE / SW / SE) containing the heavy assets (orthophoto, buildings, trees). Install only the corners you actually fly in.

Use the in-app downloader: Settings → Download Scenery. Packs are sha256-verified and extracted to a folder of your choice.

Cantons coloured green have base + detail scenery available today. Coverage currently includes all of Switzerland and Baden-Württemberg. Click any canton for details.

v1.0.4 — Scenery distribution & in-app downloader

May 2026

  • In-app scenery downloader — Settings → Download Scenery fetches base + detail quadrants from md80.ch, verifies sha256 and extracts into a folder you pick. No more manual ZIP wrangling.
  • Continue Flight — the welcome screen now offers a green Continue button to jump back into your last session after pressing Esc.
  • About dialog with full credits and third-party licenses (Godot 4.6, JSBSim, Scenery3D, swisstopo, LGL-BW, OpenStreetMap, Cessna 172 model).
  • Scenery split into per-region base packs and four detail quadrants — install only the corners you fly in.
  • Project bumped to 1.0.4, version label now read from project.godot at runtime.

v1.0.1 — First notarized macOS release

March 2026

  • Signed & notarized macOS DMG (Apple Silicon).
  • JSBSim aircraft & engine data bundled inside the app; fixed duplicate-scenery scan on APFS volumes.
  • FSX-style Scenery Library manager with per-folder enable/disable and white-pixel border fix at the CH/DE seam.
  • User-configurable joystick bindings & calibration (half-axis throttle, deadzone, invert).
  • Migrated distant terrain from Terrain3D to the in-house Scenery3D GDExtension; load progress surfaced on the loading screen.
  • Clipmap streaming + zero-copy terrain rebase eliminate the old ghost-tile bug.
  • Interactive cockpit: mixture, throttle, magneto switch.
  • Orthophoto aerial imagery layer.
  • First Windows x86_64 build with a packaged ZIP, build script and loading-screen fix for cold starts on Windows.
  • Default startup map switched to OpenStreetMap only (swisstopo tiles load on demand).
  • Windows download button added to the website; latest.json now drives both platforms.
